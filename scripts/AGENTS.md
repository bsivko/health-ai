# Общие скрипты

Наследовать корневые правила. Здесь находятся повторяемые операции, общие для
разных источников. Медицинские данные пользователя не зашивать в код.

## Прикладная обработка

Агент сам создаёт прикладной обработчик после изучения фактического документа,
архива или выгрузки. Не предполагать наличие определённого сервиса, производителя,
имен файлов, схемы экспорта, колонок или единиц. Конкретные поставщики данных
допустимы в документации только как явно обозначенные примеры.

Одноразовый скрипт и промежуточные результаты размещать в temp. Проверенную
повторяемую операцию сохранять здесь с командами, входами, результатом, зависимостями
и границами применимости. Формат источника и предметные правила не определяются
пользователем вручную: агент исследует данные и уточняет только недостающий смысл.

Перед применением нового обработчика проверить неизменность оригинала, полноту
извлечения, числа, единицы, даты, локаторы, повторения и неясности. При невозможности
проверки не объявлять результат достоверным или приём завершённым.

## Общие операции

- [materials.py](materials.py) — `verify` проверяет реестр, классификацию, SHA-256,
  связи, области и индекс; `index` обновляет навигацию из реестра. Стандартная библиотека.
- [intake.py](intake.py) — `prepare temp/reviewed.json temp/receipt.json` и
  `accept temp/receipt.json`: подготовка предварительно сверенного материала,
  проверка входов и ссылок, архивирование без перезаписи, обновление реестра и индекса.
  Формат входа описан в скрипте. OCR и содержательную сверку выполняет агент.
  Квитанцию сохранять до успеха для восстановления незавершённого переноса.
  Публикация возобновляется той же командой accept: реестр, карточки и индекс
  заменяются атомарно по отдельности; повтор не добавляет записи заново.
- [image_views.py](image_views.py) — `preview INPUT_DIR OUTPUT_DIR --prefix PREFIX`,
  `orient CONFIG_JSON`, `inspect INPUT OUTPUT.png`: миниатюры, копии с документированным
  поворотом и временное усиление читаемости. Зависимость Pillow. Оригиналы не меняются;
  улучшение контраста не доказывает правильность распознавания символов.
- [xlsx_extract.py](xlsx_extract.py) — `INPUT.xlsx OUTPUT_DIR`: извлечение ячеек,
  типов, формул, кэша и OOXML без изменения книги. Зависимость openpyxl. Раскладку
  листов, единицы и смысловые связи агент определяет по каждой новой книге.
- [medications.py](medications.py) — `verify`, `status --as-of YYYY-MM-DD`,
  `render --as-of YYYY-MM-DD`, `add-event COURSE_ID EVENT_JSON`: учёт сообщений
  пользователя по [контракту](../documentation/specs/medication-tracking.md).
  Ожидаемый приём не становится подтверждённым с течением времени.
  Состояние вычисляется по effective_date, затем recorded_date и порядку сообщений
  при равных датах. Видимая коррекция заменяет свой прежний checkpoint.
- [plot_history.py](plot_history.py) — `INPUT.json OUTPUT.png [START_DATE]`: графики
  проверенных рядов. Зависимость Pillow. Схема входа в скрипте; источники, ограничения
  и выбор значений задаёт агент. HEALTH_FONT позволяет указать TTF с кириллицей.
- [check_project.py](check_project.py) — проверка структуры, локальных ссылок,
  якорей, JSON и синтаксиса Python. `--empty` проверяет начальное пустое состояние.
  Эвристический поиск подозрительных строк не доказывает обезличивание. Только чтение.
- [smoke_test.py](smoke_test.py) — изолированные проверки приёма, сохранности,
  восстановления, обнаружения изменений и учёта по вымышленным сообщениям.
  После успеха удаляется только созданная тестом папка.
  Включает запоздалые сообщения и сбои записи реестра, карточки и индекса.

## Приём и размещение

Читать правила целевых каталогов до запуска. Выходной каталог представления должен
иметь AGENTS.md. Поле date в intake выбирает каталог. Неизвестная дата события остаётся
null и требует отдельного catalog_date_basis; дату документа не выдавать за дату взятия.
Для недатированной справочной информации допустимы reference_information и каталог
undated по [контракту](../documentation/specs/add-material.md).

Один документ может иметь несколько originals, общий скан — непересекающиеся
source_regions. Координаты box нормированы относительно исходного изображения до
поворота. archive_date позволяет отделить каталог общего носителя от даты карточки.
Детали: [формат материала](../documentation/specs/material-format.md).

Все постоянные производные файлы регистрировать в derived_files с path и sha256.
Карточки и итоговые данные не должны зависеть от temp. Точные повторные подачи
агент оформляет по контракту: готовой команды для duplicate_receipts в intake нет.

## Зависимости и проверки

Python 3.11+. Основной приём и проверки используют стандартную библиотеку.
Необязательные пакеты общих операций перечислены в [requirements.txt](../requirements.txt).
Для прикладного обработчика агент подбирает зависимости по задаче и документирует их.
Не запускать проверки с -O: часть скриптов использует assert. Проверки файлов
не заменяют сверку медицинского содержания. Команды: [CHECKS.md](../documentation/CHECKS.md).
