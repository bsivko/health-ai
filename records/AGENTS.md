# Факты, события и измерения

Здесь собираются факты из разных материалов для сопоставления без повторного чтения всех документов.

Навигация: [INDEX.md](INDEX.md), [topics](topics/AGENTS.md). Контракт: [тематическое сведение](../documentation/specs/consolidate-records.md).

- [DATABASE.md](DATABASE.md) — правила необязательной производной базы. Схема,
  источники и сборщик определяются агентом по реальным данным и задачам.
- Перед ответом по базе агент проверяет её целостность, входные хеши и охват.
  Новые или изменённые источники требуют проверенной пересборки; старое представление
  не выдавать за автоматически обновившееся состояние.

- Каждый факт ссылается на материал и доступное место в источнике.
- Различать измерение, сообщение пользователя, диагноз из заключения и назначение врача.
- Сохранять исходные значения, единицы, референсы и даты; преобразования указывать отдельно.
- Назначение препарата не подтверждает его фактический приём. Отсутствие сведений не означает отсутствие события.
- Противоречащие записи сохранять с источниками; не заменять их молча одним значением.
- Сводить подтверждённые повторы в одно событие; для расхождений показывать статус, рабочее значение с основанием либо открытый вопрос. Исходные варианты сохранять для прослеживаемости.
- Гипотезы и рекомендации не являются фактами этого слоя.
- Отсутствие факта в производной базе не означает отсутствия в проекте. Её охват всегда задаётся явно.

- [measurements](measurements/AGENTS.md) — продолжающиеся ряды регулярных измерений по датам наблюдений; [контракт](../documentation/specs/measurements.md).
- [medications](medications/AGENTS.md) — продолжающийся учёт фактического приёма по сообщениям пользователя; [контракт](../documentation/specs/medication-tracking.md).
- Для лабораторного результата первичен документ исследования. Сводку книги использовать при отсутствии соответствующего первичного результата, явно отмечая происхождение. Сопоставлять одно и то же исследование, а не только дату и похожее название; противоречия сохранять. Основание: [архитектура](../documentation/ARCHITECTURE.md).
- Способ ввода записей каждой книги уточнять у пользователя; не переносить сведения о происхождении с других книг. При отсутствии документа они допустимы как пользовательские сведения; конкретные опечатки отмечать по месту, без исключения всей книги.
